### 🎉 CMES — Entertainment Venue Content Management System

<table>
<tr>
<td width="50%" valign="top">

**ระบบจัดการคอนเทนต์บนจอสำหรับสถานบันเทิง**

</td>
<td width="50%" valign="top">

**What I worked on:**

- Recoverable queue stored in MongoDB
- Real-time Admin, User and OBS updates with Socket.IO
- JWT authentication and tenant-based shop isolation
- Service authentication between User and Admin backends
- Image upload, moderation and Cloudinary storage
- Payment slip verification and server-enforced Free mode
- Queue pause, resume, skip, retry and OBS recovery
- Rate limits, file limits and duplicate-submission protection

</td>
