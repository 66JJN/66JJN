## Selected Work

### CMES

A real-time content management and engagement system connecting user submissions, an admin dashboard, playback queues, and OBS displays.

The project began collaboratively. I later created the current CMES-ADMIN and CMES-USER repositories and have primarily rebuilt and extended the system.

Areas I worked on:

- React interfaces for users and administrators
- Node.js and Express REST APIs
- MongoDB models, indexes, and aggregation
- Socket.IO updates and recoverable playback queues
- JWT, Google OAuth, OTP, and service authentication
- Cloudinary, Gemini, Sightengine, OCR, and OBS integration
- Duplicate protection, rate limiting, and shop-based data isolation

**Status:** Ongoing prototype/pilot designed to support multiple venues.

[Case Study](https://66jjn.github.io/#/cmes-case-study) ·
[Admin Repository](https://github.com/66JJN/CMES-ADMIN) ·
[User Repository](https://github.com/66JJN/CMES-USER)

### UP TamHa

A lost-and-found web application for the University of Phayao.

The application includes searchable posts, image uploads, user accounts, claim workflows, private ownership evidence, and dashboards for tracking posts and claims.

Cloud work in this project includes:

- React and Vite front-end
- Node.js and Express API
- Azure SQL Database
- Azure Blob Storage
- Azure App Service
- Azure Static Web Apps
- GitHub Actions deployment workflows
- OIDC authentication for Azure deployment

[Repository](https://github.com/66JJN/UP-TamHa)

### AirSafeTH

A React application for checking AQI and PM2.5 by location or province, with a basic personal risk estimate and recommendations for different user groups.

It includes geolocation, external API integration, clearly labelled fallback data, responsive UI, and local assessment history.

[Live Site](https://air-safe-th.vercel.app/) ·
